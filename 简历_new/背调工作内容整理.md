# 背调工作内容整理

**主要工作：** 负责行内信息安全相关系统的后端研发，覆盖数据安全审计、业务安全风控与内部智能办公工具建设。

具体项目如下：


| 项目                   | 项目介绍                                                | 主要工作                                         | 工作成果                                                                                    |
| -------------------- | --------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------- |
| 数据安全监测中心             | 该项目用于发现和处理行内敏感数据访问、数据外传、管理台异常操作等安全风险。               | 负责数据接入、审计规则配置、风险告警和处置留痕等数据安全审计相关后端工作。        | 项目累计发现对外传输敏感数据未申报情形约100起，敏感数据外传风险识别准确率约93%，并发现多起外包人员异常操作管理台的行为，帮助安全运营人员更及时地发现和处置数据外传风险。 |
| 业务安全平台 3.0           | 该项目用于在微众银行 App 登录、转账等关键业务场景中提前识别异常操作，防范盗刷、薅羊毛等业务风险。 | 参与登录、转账等场景的风控链路建设，支持风险策略配置、风险识别和决策明细记录。      | 平台日均拦截异常操作约1000笔，策略准确率约98%，核心链路可用性约99.99%，有效降低了登录、转账场景下的盗刷、薅羊毛等业务风险。                    |
| 企业智能会议 Agent 平台（纪要君） | 该项目用于提升行内会议预订、纪要生成和事项跟进等会议处理效率。                     | 参与会议 Agent 能力建设，支持意图识别、工具调用、人工确认、纪要生成和行动项整理。 | 项目将会议纪要整理和发送耗时从人工约20分钟缩短至约2分钟，耗时减少约90%；同时将会议行动项沉淀下来持续跟进，避免纪要生成后无人处理、事项推进不闭环的问题。        |
