## 2. 组件细节

### 2.1 Spotlight（done · ADR-021）

- 代码：`spotlight_rag_chunks()` 包装 `<<UNTRUSTED_DOC id=N>>…<<END_UNTRUSTED_DOC>>`
- Gateway：`rag_gate` 清洗后写入 model context；有 RAG 时 system 追加 `SPOTLIGHT_SYSTEM_HINT`
- **不替代** `rag_gate` / `indirect_injection`

### 2.2 HiddenASCII（done · ADR-024）

- 检测 U+E0000–E007F；解码后对注入启发式打分；达阈 `block`
- 同步进入 `recursive_decode_views` 候选视图

### 2.3 decode_views + output_exfil（done）

- decode：Base64 / URL（非连续 `%XX`）/ `\uXXXX` / ROT13 hint / Unicode Tags；`MAX_DECODE_DEPTH=3`
- output_exfil：可疑 host、长 query、高熵 blob → L3 `block`

### 2.4 session_risk（partial · ADR-023）

- 条件：`ScanContext.extra.session_id` 非空（Gateway `chat(..., session_id=)`）
- 累积 injection / crescendo 信号；**同会话** inj≥1 且 crescendo≥1（且 turns≥2）→ `block`
- 进程内 dict store（有界）；非 Redis/分布式会话图
- CI：`run_multiturn_shim()` 验收晚轮 `block`

### 2.5 external_runners（partial · ADR-022）

| suite | CI | 集群 Job |
| --- | --- | --- |
| multiturn_shim | 进程内 | — |
| garak / agentic_security / pyrit / purplellama_cse | 仅 manifest | `SAFETY_EXTERNAL_REDTEAM=1` 才按描述符拉起 |

**禁止** `import` study 树进 Gateway / scanners。
