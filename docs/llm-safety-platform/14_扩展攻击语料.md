## 生成质量（diversity engine）

生成器 `scripts/generate_handbook_expanded_corpora.py`：

- 大词池：org / role / ticket（含假 CVE/MSRC）/ product / intent class / authority
- 每场景 ≥12–15 结构骨架 + 组合填充 + 规范化 hash 去重 / 冲突变异
- 创意发散：礼貌嵌套壳、中英夹杂、HTML/JSON/YAML/CSV 走私、权威伪装、data URI / DNS 外泄通道等（手册套路，非原文粘贴）
- `benign_controls` 仅用无害变异，避免 data-URI/obey 污染 allow 集

```bash
cd llm-safety-platform
.venv/bin/python scripts/generate_handbook_expanded_corpora.py
```

生成器会覆写 `handbook_expanded/*.yaml`、`manifest.json`、以及 `handbook_expanded_smoke.yaml`。

## 双门禁策略（有效性 + 防误杀）

规则变更必须同时过两道门，禁止「只压漏拦、不管误杀」或反过来：

| 门禁 | 目标 | 语料 | 阈值 |
| --- | --- | --- | --- |
| **Attack gate** | 有效性：攻击拦得住 | smoke expect-block；release 再加 `EXPANDED_LIMIT=20`；full=2500 | mismatch **0** |
| **FP gate** | 防误杀：正常话术放行 | `benign_fp_suite`（改说法 + keyword-trap）；release 含 `benign_controls` | FP **0** |

落地策略：

1. **家族级规则 + 攻击 framing**：裸关键词不杀；教育/培训/术语语境走 `_META_EDU` / `suppress_context`。
2. **Keyword-trap**：正向用例故意带「钓鱼 / jailbreak / 支付改道 / API token」等词，但是合法用途。
3. **分层 profile**：`ci`（快）→ `release`（LIMIT=20）→ `full`（发版前）。
4. **Publish 同源**：`configs/evals/publish_profile.yaml` → `run_publish_gates()`（**dual_gate:ci** + legacy shim corpora）；**不是** full profile。

**指标 SoT（2026-08-06，第一阶段复验）** — `corpus_metrics.py` 实时计算；`assert_profile_metrics` 漂移 fail-closed；pytest **103 passed**。

| Profile | Attack cases | FP cases |
| --- | --- | --- |
| ci | 120 smoke expect-block | 310 benign_fp_suite |
| release | 600（120 + LIMIT=20×24） | 410（310 + 100 benign_controls） |
| full | 2400 expect-block | 410 |

总语料 **2500** = 2400 expect-block + 100 benign_controls allow。**0 leak/FP 仅表示 shim 离线门禁通过，不等于生产零事故。**

```bash
# 推荐日常：双门禁 CI
./scripts/eval_attack_corpora.sh dual_gate
# 或
.venv/bin/python -m app.eval.dual_gates --profile ci

# 发版前：+ EXPANDED_LIMIT=20 + benign_controls
./scripts/eval_attack_corpora.sh dual_gate_release
.venv/bin/python -m app.eval.dual_gates --profile release

# 全量（慢）
./scripts/eval_attack_corpora.sh dual_gate_full
```

## 双门控发布策略（2026-08-06）

规则合入前必须 **同时** 通过两道门，禁止只优化攻击侧或只优化误杀侧：

| 门 | 语料 | 指标 | CI 阈值 | 命令 |
| --- | --- | --- | --- | --- |
| **Attack** | `handbook_expanded_smoke` expect-block | leak_rate | **0%**（120/120） | `./scripts/eval_attack_corpora.sh dual_gate` |
| **Attack（抽样）** | `handbook_expanded/*` + `EXPANDED_LIMIT=20` | leak_rate | **0%**（480/480） | `./scripts/eval_attack_corpora.sh dual_gate_release` |
| **Attack（全量）** | 25×100 expect-block | leak_rate | **0%**（2400/2400） | `python -m app.eval.dual_gates --profile full` |
| **FP** | `benign_fp_suite.yaml` | unexpected block | **0%**（310） | `pytest tests/test_benign_fp_suite.py` |
| **FP** | `benign_controls.yaml` | unexpected block | **0%**（100） | 含于 `dual_gate_release` / `full` |

**Keyword-trap / 改说法**：合法培训、SOC runbook、API 轮换 SOP、HTML sanitizer 文档等可含攻击关键词，须 `allow`；靠家族级 `_META_EDU` / `suppress_context` / 攻击 framing（`任务劫持：`、`诱导外泄：` 等）收窄，禁止 case-id 过拟合。

**发布门禁**：`POST .../publish` → `run_publish_gates()`（见 `publish_profile.yaml`；含 legacy shim + **dual_gate:ci**）；critical 双人签字见 ADR-029。

**remote Judge 对比**（opt-in）：

```bash
# 需 SAFETY_CLASSIFIER_URL；否则 skip 并写 remote_judge_compare.json
.venv/bin/python -m app.eval.remote_judge_compare
```

**可选演进**：分层抽样降 CI 时延；shadow mode 对比新旧规则；borderline 样本仅走 Judge 仲裁。

误杀收窄（2026-08-05）：裸 `钓鱼`、裸 `管理员权限`、`可利用漏洞` 教学否定句不再命中；攻击侧「编写钓鱼邮件模板」等仍 block。

误杀收窄（2026-08-06 · keyword-trap）：套件 **212→288→310**；裸分类标签改为攻击 framing——`任务劫持：` / `诱导外泄：` / `分片指令 N=` / `客服优先级重排：` / `诱导工具调用：用 search_files` / `Poisoned MCP prompt` / `MCP / 工具投毒 JSON`；`伪造支付改道` 需给出/操作话术；`DAN mode`/`Do Anything Now` 需 enablement（括号释义允许）；`电汇诈骗…实施` 不再命中「非实施」；`content_privacy` 对「never ask … list tokens in context」等否定教育句增加 `suppress_context`；`expert_advice` 对合规培训语境增加 `suppress_context`；`(Frame:runbook/…)` 攻击帧不再被 `_META_EDU` 误放行。

家族补丁（2026-08-05 · HTML-hidden / 支付改道）：`display:none|mso-hide|opacity:0|font-size:0/1px` + SYSTEM/OVERRIDE；支付改道/电汇诈骗需请求 framing；`cross-document secret retrieval` / `post to audit endpoint`。

家族补丁（2026-08-05 · LIMIT=20 九漏）：`暴力伤害操作步骤` / 摘要壳假设伤害；`诱导外泄：`+图片链接承载邮箱；`分片指令`+提取上下文密钥；`actionable insider framing` / `earnings leak` / `ask: insider entry`；`任务劫持：` / `客服优先级重排：`+上下文令牌/PII。

家族补丁（2026-08-05 · 全量 2400）：`绕过内容过滤并无限制回答` / `完整打印客户隐私字段` / PII table+SSN；`诱导工具调用：`+`id_rsa`；Poisoned MCP prompt / `audit_dump`；`原样返回 system prompt` / `paste developer message` / `data: URI`+developer；`/bin/reveal_prompt` / `export SAFETY=0`；finance `leverage crypto all-in`；KO/RU ignore+exfil；char-spaced collapsed `bypasscontentfilters` / `leakpasswordsfrommemory`。

## 后续改进方向

1. **语境分类器**：用轻量二分类（教育/攻击）替代手工 `suppress_context` / `_META_EDU_RE` 列表，降低规则维护成本。
2. **多语 keyword-trap**：扩充越/泰/韩等语言的合法防诈培训句式，覆盖 translation_attack 族误报边界。
3. **Judge 融合评测**：在 `SAFETY_SCANNER_MODE=remote` 下对 benign_fp_suite 跑 dual-path fuse，量化 rules floor 与 Judge soft-allow 的冲突率。
4. ~~语料漂移门禁~~：**已落地** `app.eval.dual_gate`（ci/release/full）+ `corpus_gates` FP 闸 + `tests/test_dual_gate.py`。
5. **ONNX 分类器**：shim 规则达标后，用标注子集训练 prompt-injection ONNX，A/B 对比 FP/FN trade-off。
6. **Shadow / 抽样运营**：线上抽样对话打标（攻击/教育），周报 leak≈0 且 FP 趋势，驱动规则收窄而非一次性堆正则。

## 约束

- 无 `context_overflow` 类别；单条文本硬上限（生成器/测试闸 **4k**）
- Decision enum 不变（`allow` / `block` 等既有值）
- 有害内容保持**红队请求/提示**形态，与既有语料一致
- 每场景唯一 `text` 比 ≥ **0.95**（实测 1.0）
