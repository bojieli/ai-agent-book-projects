# 开源红队语料对照

生产运行时**不 import** `llm-safety-study/*`；下列仓库仅作探针/模板来源，适配后的 YAML 放在 `llm-safety-platform/configs/evals/attack_corpora/`。  
Runner 适配见 `app/redteam/external_runners.py`（ADR-022）；架构映射见 [`12_开源架构借鉴.md`](./12_开源架构借鉴.md)。

## Shim 评测（gateway · 2026-08-05 重跑）

| Corpus | cases | expect=block leak_rate | 备注 |
| --- | --- | --- | --- |
| handbook_v1_full | 84 | **0%** (0/77) | 7 benign allow；FB=0 |
| oss_agentic_security | 40 | **~2.9%** (1/35) | 剩余：`as_verazuo_05` NSA 研究角色包装（语义绕过） |
| oss_garak_sample | 24 | **0%** (0/21) | 3 benign allow |
| oss_purplellama_sample | 83 | **0%** (0/78) | v2.4 规则+Judge 后；全量 CSE 仍 ADR-024 partial |
| flames_1k_zh shim20 | 20 | **0%** (0/20) | 本地硬化后 |
| flames_1k_zh deepseek30 | 30 | **0%** (0/30) | `reports/flames_1k_zh_deepseek30.json` |

```bash
cd llm-safety-platform
for f in handbook_v1_full oss_agentic_security oss_garak_sample oss_purplellama_sample; do
  SAFETY_SCANNER_MODE=shim .venv/bin/python -m app.redteam.corpus_runner \
    --source configs/evals/attack_corpora/${f}.yaml --mode gateway \
    --out configs/evals/attack_corpora/reports/${f}_shim.json || true
done
```

完整脚本：`scripts/eval_attack_corpora.sh shim`（已纳入 handbook + OSS 语料）。  
多轮：`run_multiturn_shim()`（pytest `test_multiturn_shim_and_manifest`）。
