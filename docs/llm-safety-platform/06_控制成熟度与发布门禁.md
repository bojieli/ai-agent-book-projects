## 3. 故事门禁矩阵

| Story | 必过断言 |
|-------|----------|
| S1 注入 | decision=block；无 model 成功旁路 |
| S2 PII | decision=redact；上游无原文；可信侧可还原 |
| S3 邮件外发 | tool.denied 或 confirm_only；无静默 execute |
| S4 输出密钥 | L3 block 或 redact |
| S5 投顾跑题 | BanTopics block 或安全拒答 |
| S6 Token 炸弹 | TokenLimit block |
| S7 策略追加 | version 单调；旧版不变 |
| S8 门禁拦截 | ReleaseEvaluator failed → publish 不生效（ADR-018） |
| S9 双人发布 | critical 缺第二审批人 → 拒绝 |
| S10 哈希链 | 决策落链；篡改可被 verify 检出 |

## 4. 可执行发布流水线

```text
策略 diff（append-only draft）
  → ReleaseEvaluator（契约 + 负例 + 红队摘要）     ← 硬阻塞（ADR-018）
  → promptfoo 回归（变更必跑）
  → garak / PyRIT（涉及 injection/jailbreak 时强制）
  → risk_tier=critical？→ 双人签字（Security + Admin/AppOwner）
  → policy.published（INSERT version+1；写 publish_gate）
  → 金丝雀租户 → 全量
```

**可执行门禁（CI / `run_all`）**

| Gate | 命令/检查 | 失败行为 |
|------|-----------|----------|
| 架构契约 | `verify_architecture` | 阻断 |
| 单元/故事 | `pytest`（S1–S10 子集） | 阻断 |
| Scanner | `SAFETY_SCANNER_MODE=shim` 默认全绿 | 阻断 |
| Evaluator | `ReleaseEvaluator` on fixture diff | failed → 禁止 publish API 提交 |
| **双门控** | `./scripts/eval_attack_corpora.sh dual_gate`（attack smoke + benign_fp） | 任一 leak/FP → exit 1 |
| **双门控（发版）** | `dual_gate_release` / `dual_gates --profile full` | 同上 |
| **Publish profile** | `run_publish_gates()` 各门 enabled/blocking + gates_audit | 默认 dual_gate:ci |
| **critical 重评** | 最终双人批准前重跑 publish gates | 失败 → gate=failed |
| **指标 SoT** | `corpus_metrics.py` 从 YAML 计算 | 漂移 fail-closed |
| **remote Judge 对比** | `python -m app.eval.remote_judge_compare` | 无 `SAFETY_CLASSIFIER_URL` → skip（不假装绿） |
| 双人 | `require_dual_publish` + 两名不同 subject | 缺一则 403 |
| **链完整** | `/v1/admin/audit/chain/verify` graph 重建 | fork/断链/孤儿 fail-closed；legacy 回填见 `migrate.py` |

**回滚**：发布 `version+1` 指向上一策略内容（仍 append，不删历史）。

## 5. 度量

| 指标 | 定义 |
|------|------|
| 漏拦率 | 红队应拦未拦 / 应拦总数 |
| 误拦率 | benign 被 block / benign 总数 |
| P99 网关延迟 | 不含上游 LLM（目标见 04） |
| Vault 命中率 | 含 PII 请求成功 redact 比例 |
| Tool deny 率 | denied / tool attempts（突增告警） |
| 门禁拦截次数 | Evaluator failed / publish 尝试 |
| 哈希链断裂 | verify 失败次数（须=0）；以 DB `audit_decisions` 为准 |
| 语料规模（SoT） | 2500 总 / 2400 expect-block / ci FP 310 / release·full FP 410 |
