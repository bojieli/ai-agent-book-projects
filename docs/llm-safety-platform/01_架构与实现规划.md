## 1. 产品定位

组织内所有 LLM / Agent 流量的**统一安全控制面**（金融行内私有化）：

- Online：Gateway、四层护栏、PII Vault、虚拟密钥、多模路由、预算限流  
- **工具风险**：黑白名单、危险操作（参数级）识别、调用全量审计、HITL 例外  
- 治理：多租户策略、RBAC/OIDC、控制台、双人发布  
- Offline：promptfoo / garak / PyRIT → ReleaseEvaluator → 策略发布门禁  
- 合规：OTel、SIEM、哈希链审计

## 4. 硬规则

1. Gateway 唯一入口；旁路不合规  
2. ToolRuntime 唯一侧效；VK 不得持有上游 Provider Key  
3. `policy_binding` 只追加更严版本  
4. 决策枚举：`allow|redact|block|confirm_only|alert_only`  
5. high/critical **fail-closed**  
6. PII 出可信域必 Vault 脱敏  
7. 策略发布必须过 ReleaseEvaluator；critical 双人审批  
8. 对照仓只读，生产代码仅 `llm-safety-platform/`
