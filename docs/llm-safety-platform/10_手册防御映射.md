# Prompt Injection 手册 → 平台映射

参考：[SecureNexusLab / Zero《LLM Prompt Injection Security Handbook》V1.0](https://github.com/SecureNexusLab/LLMPromptAttackGuide)（本地 PDF：`llm-prompt-injection-security-handbook V1.0.pdf`）。  
**精读与原文案例**见 [`13_手册精读与案例.md`](./13_手册精读与案例.md)。

手册结论：注入不可根除，目标是抬高攻击成本（纵深防御）。平台决策枚举保持 `allow|redact|block|confirm_only|alert_only`；手册的 CLEAR / SUSPICIOUS / BLOCKED 大致对应 `allow` / `alert_only` / `block`。

开源红队语料见 [`11_开源红队语料.md`](./11_开源红队语料.md)；架构借鉴总表见 [`12_开源架构借鉴.md`](./12_开源架构借鉴.md)。

## 四层对照（手册 §8.5）

| 手册层 | 平台落点 | 状态 |
| --- | --- | --- |
| 外部边界：限速 / 鉴权 / 审计 | Gateway budget+concurrency、审计 hash-chain、VK | 部分（OIDC/KMS/SIEM 待产线） |
| 输入层：过滤 / 编码 / 语义 | `normalize`、`decode_views`、`hidden_ascii`、规则+`content_safety`、remote Judge | 规则+递归解码+HiddenASCII 已上；语义向量库未上 |
| 模型层：硬化提示 / Dual-LLM / 上下文 | Spotlight datamark（ADR-021）；业务 system prompt；**Dual-LLM 延期**（ADR-023） | Spotlight done；Dual-LLM deferred |
| 输出层：分类 / Judge / 人工 | L3 scanners、HITL、`output_exfil` | Judge+敏感+外泄启发式已接 |

## 明确不做 / 后续（挂 ADR）

1. Dual-LLM（查询分析与执行物理隔离）— **ADR-023 Deferred**  
2. 完整会话图 / 角色漂移探针 — **ADR-023**（超出 `session_risk` shim）  
3. Sentence-Transformer 语义攻击库 — 需模型权重与阈值标定（上线前补 ADR）  
4. 对抗后缀优化攻击的专用检测 — 依赖 Judge/分类器，规则层覆盖有限  
5. `output_exfil` 完整命中依赖模型输出侧；输入语料无法单独充分覆盖（已有 unit test）  
6. AlignmentCheck 全量 LLM trace — **ADR-024 Deferred**
