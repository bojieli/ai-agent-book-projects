## 1. 字段说明

| 字段 | 含义 |
|------|------|
| mode | `sop` \| `playbook` |
| maturity | L0–L3（见 03 §2.8） |
| classification | public \| internal \| confidential \| critical |
| write_class | wide \| domain \| sealed \| none |
| default_embed_gate | allow \| confirm_only \| block |
| production_effect_cap | none \| draft_only \| observe \| production |
| V1 | 是否本阶段必交付 |

## 4. 门禁

1. CI：变更 Skill / Policy / 索引规则必须跑对本故事 eval。  
2. `governance.status=approved` 前不得被生产 Pipeline 加载。  
3. L3 无真实 `sop/steps.yaml` → 不准合并。  
4. critical 无 sealed/none write_class → 不准合并。  

样例实现见 `samples/skills/`（V1 12 包齐备）与绿场代码 [`jiyaojun/`](../../jiyaojun/)。
