## 📑 مرور محتوا (فصل‌های ۱ تا ۱۰)

| فصل | موضوع | خلاصه یک‌خطی |
| :--: | --- | --- |
| ۱ | 🚀 **مبانی AI Agent** | **Agent = LLM + کانتکست + ابزارها**؛ مهندسی Harness مزیت رقابتی اصلی است |
| ۲ | 🎯 **مهندسی کانتکست (Context Engineering)** | کانتکست سقف توانمندی عامل را تعیین می‌کند: KV Cache، پرامپت نویسی، مهارت‌ها و فشرده‌سازی |
| ۳ | 📚 **حافظه کاربر و پایگاه دانش** | حفظ حافظه بین جلسات و اتصال به دانش خارجی: RAG، گراف دانش و نمایه‌های ساختاریافته |
| ۴ | 🛠️ **ابزارها (Tools)** | ابزارها دستان عامل هستند: پروتکل MCP، ابزارهای ادراکی/اجرایی و کشف خودکار ابزار |
| ۵ | 💻 **Coding Agent و تولید کد** | کد «ابزاری است که ابزارهای جدید می‌سازد»؛ عامل‌های کدنویسی سطح تولید |
| ۶ | 🎯 **ارزیابی عامل‌ها (Evaluation)** | تبدیل عملکرد به سیگنال‌های قابل مقایسه: محیط‌ها، متریک‌ها و ارزیابی آماری |
| ۷ | 🧠 **پس‌آموزش مدل (Post-Training)** | مراحل پیش‌آموزش، SFT و RL: درونی‌سازی فراخوانی ابزارها و کارایی نمونه‌ها |
| ۸ | 🔄 **خود-تکاملی مداوم عامل‌ها** | رشد و تکامل بدون تغییر وزن‌ها: یادگیری از تجربیات و تبدیل از کاربر ابزار به سازنده ابزار |
| ۹ | 🎙️ **چندتعاملی و تعامل بی‌درنگ** | گسترش متن به صوت، رابط کاربری GUI و دنیای واقعی: مدل‌های صوتی، Computer Use و رباتیک |
| ۱۰ | 🤝 **همکاری چند عامل (Multi-Agent)** | هوش جمعی بالاتر از هوش فردی: چارچوب‌های همکاری، اشتراک‌گذاری/جداسازی کانتکست و جامعه عامل‌ها |
