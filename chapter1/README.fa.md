# آزمایش‌های فصل ۱: مبانی AI Agent

این پوشه شامل پروژه و آزمایش‌های مرتبط با فصل ۱ (مبانی Agent) است.

## لیست آزمایش‌ها:

1. **الگوی ReAct ساده:** پیاده‌سازی حلقه ReAct (Reasoning + Acting) با قابلیت فراخوانی ابزارهای حسابداری و ابزار جستجو.
2. **مدیریت خطای فراخوانی ابزار:** نحوه مواجهه عامل با خطاهای اجرایی ابزار و بازسازی پرامپت جهت اصلاح خطای خودکار.
3. **پروتکل پایه ارتباط با ابزار:** فرمت‌بندی JSON Schema برای توصیف ابزارها به مدل زبانی.
