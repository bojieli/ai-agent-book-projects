# AI 安全治理

该上下文负责对模型交互和工具行为作统一安全判决，并确保策略变更可评估、可审批、可追踪。

## 在线判决

**安全请求（Safety Request）**：
等待安全治理的模型输入、模型输出或工具行为。
_Avoid_: Prompt、聊天消息

**风险证据（Risk Evidence）**：
某项检测对风险事实的结构化陈述，本身不直接决定最终处置。
_Avoid_: 告警、最终结论

**安全判决（Safety Decision）**：
安全治理对一次请求给出的唯一最终处置，包括放行、脱敏、阻断、人工确认或仅告警。
_Avoid_: Scanner 结果、风险分数

**检测器（Scanner）**：
针对确定风险类型收集风险证据的能力。
_Avoid_: Judge、策略引擎

**语义审核器（Judge）**：
对边界语义作补充判断的审核能力，不能放宽确定性安全约束。
_Avoid_: Scanner、最终判决器

**操作风险（Operation Risk）**：
工具行为可能对外部系统或受保护数据造成影响的业务风险。
_Avoid_: 内容风险、策略风险

**数据出站（Data Egress）**：
受保护内容离开本系统边界并交给外部模型服务处理的行为。
_Avoid_: 普通模型调用、日志发送

**灰区请求（Ambiguous Request）**：
确定性规则无法可靠给出安全判决，需要语义审核或人工确认的请求。
_Avoid_: 所有未命中规则的请求、低风险请求

## 策略与发布

**策略绑定（Policy Binding）**：
某类调用在特定范围内必须遵循的版本化安全规则集合。
_Avoid_: 配置文件、当前规则

**攻击门（Attack Gate）**：
验证应被阻断的攻击样本是否出现漏拦的发布条件。
_Avoid_: 误杀门、总发布门

**正常业务门（Benign Gate）**：
验证应被允许的正常样本是否出现误杀的发布条件。
_Avoid_: 攻击门、白名单

**发布判定（Publish Decision）**：
综合评测结果、审批状态和风险等级后，对策略版本能否生效作出的决定。
_Avoid_: 测试通过、部署完成

## 身份与审计

**虚拟密钥（Virtual Key）**：
业务应用调用安全控制面的受管身份，不暴露上游模型凭据。
_Avoid_: 模型 API Key、用户登录令牌

**审计链（Audit Chain）**：
按先后关系连接的安全判决记录，用于发现记录缺失、分叉或篡改。
_Avoid_: 普通日志、事件列表
