# 제7장 · 모델 사후 학습

> 사전 학습, SFT, RL이라는 세 단계를 종합적으로 살펴봅니다. SFT와 RL을 선택하는 기준, RLHF, 알고리즘 비교, 데이터와 환경을 다루고, 모델에 도구 호출을 가르치고 샘플 효율성을 높이기 위한 최신 연구를 탐구합니다.

← [한국어 메인 README로 돌아가기](../docs/ko/README.md) · 📖 [제7장 본문 읽기](../book-ko/chapter7.ko.md)

## 연계 프로젝트

| 실험 | 프로젝트 | 유형 | 설명 |
| :--: | --- | :--: | --- |
| 7-3, 7-4 | [MiniMind-pretrain](MiniMind-pretrain/) | 📖 | 소형 언어 모델을 처음부터 사전 학습해 전체 사전 학습 과정과 핵심 기술을 이해합니다. |
| 7-5 | [continued-pretraining](continued-pretraining/) | ✅ | 도메인 특화 데이터로 계속 사전 학습을 수행해 대상 도메인에서 모델 성능을 높입니다. |
| 7-6 | [sesame](sesame/) | ✅ | Sesame CSM 음성 SFT: 1B TTS 모델을 LoRA로 미세 조정하고 `<laugh>`, `<sigh>` 같은 준언어 태그로 표현을 제어합니다. |
| 7-6 | [orpheus](orpheus/) | ✅ | Orpheus 3B 음성 SFT: TTS 모델을 LoRA로 미세 조정하고 참조 음성을 이용한 음성 복제로 문장 사이의 음색 일관성을 유지합니다. |
| 7-7 | [MultilingualReasoning](MultilingualReasoning/) | ✅ | 여러 언어 환경에서 모델의 사고 능력을 학습시켜 언어 간 작업 성능을 높입니다. |
| 7-9 | [cot-distillation](cot-distillation/) | ✅ | OpenRouter를 통해 Claude 같은 최첨단 모델에서 CoT 궤적을 증류하고, 규칙으로 검증한 뒤 SFT 데이터로 변환합니다(실험 7-9 연계). |
| 7-10 | [AdaptThink](AdaptThink/) | 📖 | 사고 모델이 문제 난이도에 따라 사고 방식(Thinking 또는 NoThinking)을 적응적으로 고르도록 학습합니다. 제약 최적화와 중요도 샘플링을 통해 정확도를 높이면서 사고 비용을 45~69% 크게 줄입니다. DeepSeek-R1-Distill-Qwen 모델을 기반으로 DAPO 알고리즘을 사용해 학습합니다. |
| 7-11 | `SFTvsRL/` | 📖 | 여러 작업에서 지도 미세 조정(SFT)과 강화 학습(RL)의 효과를 체계적으로 비교하고, 두 방법의 장단점과 적합한 적용 시나리오를 분석합니다. |
| 7-12 | [SpatialReasoning](SpatialReasoning/) | 📖 | 위치, 방향, 거리 같은 공간 관계가 포함된 문제를 처리하도록 모델의 공간 사고 능력을 학습하는 데 초점을 맞춥니다. |
| 7-13 | [SimpleVLA-RL](SimpleVLA-RL/) | 📖 | 강화 학습에서 시각·언어·행동을 결합해 모델이 시각 입력을 이해하고 그에 맞는 행동을 실행하도록 학습합니다. |
| 7-14 | [RLVP](RLVP/) | 📖 | RLVP 사후 학습 연구로, 결과에는 보상을 주고 경로에는 벌점을 부여합니다(실험 7-14 연계). 전체 학습·평가 코드는 별도 논문 저장소 `19PINE-AI/rlvp`에 있으므로 직접 clone해야 합니다. |
| 7-15 | [retool](retool/) | 📖 | 다중 턴 대화와 코드 샌드박스로 대규모 언어 모델의 수학적 사고 능력을 높입니다. SFT와 RL의 2단계 학습을 거쳐 모델이 코드 실행 환경을 활용해 수학 문제를 풀도록 합니다. Qwen2.5-32B-Instruct를 기반으로 AIME 2024 데이터셋, DAPO 알고리즘, SandboxFusion 샌드박스를 사용합니다. |
| 7-16 | `AWorld/` · [AWorld-train](AWorld-train/) | 📖 | AWorld 프레임워크를 기반으로 체화 에이전트를 학습해 가상 환경에서 복잡한 작업을 수행하고 경험으로부터 배우게 합니다. |
| — | `verl/` | 📖 | verl은 대규모 언어 모델의 RLHF 학습을 위해 설계된 효율적인 강화 학습 프레임워크로, PPO, GRPO, DAPO 등 여러 알고리즘을 지원합니다. |
| — | [Intuitor](Intuitor/) | ✅ | 모델의 직관적 사고 능력을 학습해 상세한 사고 사슬 없이도 빠르고 합리적인 판단을 내릴 수 있게 합니다. |
| — | `tinker-cookbook/` | 📖 | 모델 학습을 위한 여러 실전 팁과 모범 사례를 모았습니다. |
