# الفصل العاشر · التعاون متعدد الوكلاء

> قد يفوق الذكاء الجمعي ذكاء الفرد. ويعرض الفصل إطارًا لتصنيف الأنظمة متعددة الوكلاء، ومتى تتفوق فعليًا على الوكيل الواحد، والتعاون بسياق مشترك أو مستقل، وأنماط الفشل، ومجتمعات الوكلاء الناشئة.

← [العودة إلى الملف التمهيدي الرئيسي](../docs/ar/README.md) · 📖 [قراءة نص الفصل](../book-ar/chapter10.ar.md)

## المشاريع المصاحبة

| التجربة | المشروع | النوع | الوصف |
| :--: | --- | :--: | --- |
| 10-1 | [موجّه النظام المرحلي](staged-system-prompt/) | ✅ | يحمّل وكيل البرمجة نفسه موجّهات نظام ومجموعات أدوات مختلفة في مراحل المهمة: توضيح المتطلبات، ثم تنفيذ الشفرة، ثم مراجعتها. وبذلك يؤدي أدوارًا مختلفة داخل المحادثة نفسها، مع استمرار مشاركة سجل الحوار وحالة المهمة بين المراحل. وإذا فشلت المراجعة، يمكنه العودة إلى مرحلة التنفيذ. |
| 10-2 | [التسليم متعدد الأدوار](multi-role-transfer/) | ✅ | يوضح تسليم المهمة بالتتابع داخل سياق مشترك. تضم الجلسة عدة وكلاء متخصصين، لكل منهم موجّه نظام وأدوات مخصصة. وباستخدام `transfer_to_agent` يقرر الوكيل متى ينتقل إلى دور آخر وفق تقدم المهمة. ولأن الوكلاء يشتركون في سجل الحوار نفسه، يبقى السياق كاملًا أثناء التسليم. |
| 10-3 | [ترجمة الكتاب](book-translation/) | ✅ | يستخدم نمط المدير لتقسيم ترجمة الوثائق الطويلة بين وكلاء متخصصين في المسرد والترجمة والتدقيق. ولا يحتفظ المدير إلا بالمهام والخطط وسجلات الاستدعاء ومؤشرات الملفات، بينما يُكتب النص المترجم كاملًا إلى القرص، فيبقى حجم السياق شبه ثابت. ويقارن ذلك بنهج الوكيل الواحد باستخدام أعداد فعلية للرموز، موضحًا ضبط تضخم السياق والحفاظ على اتساق الكتاب بمسرد مشترك. |
| 10-4 | `use-computer-while-calling/` | 📖 | يطبق بنية تعاون بين وكيل للهاتف وآخر لاستخدام الحاسوب. ويتواصل الوكيلان مباشرة عبر WebSocket من دون منسق؛ فيدير الأول الحوار الصوتي، ويؤتمت الثاني المتصفح، ويعملان بالتوازي في المهام التي تجمع الصوت والويب. وقد تطورت الشفرة إلى مشروع [TalkAct](https://github.com/19PINE-AI/TalkAct) المستقل، ولا يتضمن هذا المستودع دليله؛ راجع ملحق README الرئيسي لأمر الاستنساخ. |
| 10-6 | [بحث الويب المتوازي](parallel-web-research/) | ✅ | يوضح بحثًا متوازيًا لوكلاء متماثلين بتنسيق مركزي. يطلق المنسق N وكلاء فرعيين في وقت واحد، ويبحث كل منهم في مصدر واحد، ثم يتوقف الباقون فور عثور أحدهم على الإجابة. وينفذ المشروع ناقل الرسائل والتوزيع المتوازي والمراقبة الآنية والإنهاء المتسلسل ومعالجة حالات السباق، باستخدام مصادر معلومات محاكاة قابلة للتحكم. |
| 10-7 | `generative_agents/` | 📖 | وكلاء «مدينة الذكاء الاصطناعي» في Stanford، المصاحبون للتجربة 10-7. يجب استنساخ المستودع الخارجي `joonspk-research/generative_agents` يدويًا؛ راجع ملحق README الرئيسي. |
| 10-8 | [لعبة المستذئب الصوتية](voice-werewolf/) | ✅ | يستخدم لعبة مستذئب متعددة الوكلاء لشرح ضبط الوصول إلى المعلومات في «السياق المستقل». فكل لاعب وكيل مستقل ذو سياق خاص معزول، ويحدد حكم حتمي قائم على الشفرة المعلومات التي تصل إلى كل لاعب، ويسجلها للتدقيق، ويتحقق آليًا من سلامة العزل في نهاية اللعبة. والصوت إضافة اختيارية. |
