# 제10장 · 멀티 에이전트 협업

> 집단 지능은 개별 지능을 넘어설 수 있습니다. 멀티 에이전트 분류 체계, 단일 에이전트보다 실제로 뛰어난 경우, 컨텍스트를 공유하거나 격리하는 협업, 실패 유형, 새롭게 나타나는 ‘에이전트 사회’를 다룹니다.

← [한국어 메인 README로 돌아가기](../docs/ko/README.md) · 📖 [제10장 본문 읽기](../book-ko/chapter10.ko.md)

## 연계 프로젝트

| 실험 | 프로젝트 | 유형 | 설명 |
| :--: | --- | :--: | --- |
| 10-1 | [staged-system-prompt](staged-system-prompt/) | ✅ | 같은 코딩 에이전트가 작업의 실행 단계(요구사항 명확화 → 코드 구현 → 코드 리뷰)에 따라 서로 다른 시스템 프롬프트와 도구 모음을 불러옵니다. 하나의 대화 안에서 역할과 행동을 바꾸면서도 단계 사이에 대화 기록과 작업 상태를 계속 공유합니다. 리뷰에 실패하면 구현 단계로 되돌아갈 수 있습니다. |
| 10-2 | [multi-role-transfer](multi-role-transfer/) | ✅ | 공유 컨텍스트에서 연쇄 인계하는 방식을 보여 줍니다. 하나의 세션 안에 각자 고유한 시스템 프롬프트와 전용 도구 모음을 가진 여러 전문 역할 에이전트가 있습니다. 에이전트는 `transfer_to_agent` 도구로 작업 진행 상황에 따라 다른 역할로 전환할 시점을 스스로 결정합니다. 같은 대화 기록을 공유하므로 인계 과정에서도 전체 컨텍스트가 자연스럽게 보존됩니다. |
| 10-3 | [book-translation](book-translation/) | ✅ | 오케스트레이터 모드로 긴 문서 번역을 용어집·번역·교정 전문 에이전트에게 분해합니다. 관리자는 작업, 계획, 호출 기록, 파일 색인만 보관하고 완성된 번역문은 디스크에 기록해 컨텍스트 크기를 거의 일정하게 유지합니다. 단일 에이전트 방식과 실제 토큰 수를 비교해 컨텍스트 폭증을 억제하고 공통 용어집으로 책 전체의 일관성을 지키는 방법을 보여 줍니다. |
| 10-4 | `use-computer-while-calling/` | 📖 | 전화 통화 에이전트와 Computer Use 에이전트로 구성된 이중 에이전트 협업 아키텍처를 구현합니다. 두 에이전트는 조정자 없이 WebSocket으로 직접 통신합니다. 전화 에이전트는 음성 상호작용을, 컴퓨터 에이전트는 브라우저 자동화를 담당하며 병렬로 작업해 음성과 웹 작업이 모두 필요한 복잡한 과제를 완료합니다. 코드는 독립적으로 유지보수되는 [TalkAct](https://github.com/19PINE-AI/TalkAct)로 발전했으며 이 저장소에는 해당 디렉터리가 없습니다. clone 명령은 메인 README 부록을 참고하세요. |
| 10-6 | [parallel-web-research](parallel-web-research/) | ✅ | 중앙 조정 아래 여러 동종 에이전트가 병렬 검색하는 방식을 보여 줍니다. 주 조정자가 N개의 하위 에이전트를 동시에 시작하고, 각 에이전트는 하나의 정보 소스에서 답을 찾습니다. 하나가 목표를 찾으면 나머지는 정상적으로 종료합니다. 실제 브라우저 대신 제어 가능한 모의 정보 소스를 사용하면서도 메시지 버스, 병렬 실행, 실시간 모니터링, 연쇄 종료, 경쟁 상태 처리를 사실적으로 구현합니다. |
| 10-7 | `generative_agents/` | 📖 | Stanford의 ‘AI 마을’ 생성형 에이전트입니다(실험 10-7 연계). 외부 저장소 `joonspk-research/generative_agents`를 직접 clone해야 하며, 메인 README 부록을 참고하세요. |
| 10-8 | [voice-werewolf](voice-werewolf/) | ✅ | 멀티 에이전트 마피아 게임으로 ‘비공유 컨텍스트’의 정보 접근 통제를 보여 줍니다. 각 플레이어는 개인 컨텍스트가 엄격히 격리된 독립 LLM 에이전트입니다. 코드 기반 결정론적 심판이 어떤 정보를 어느 플레이어의 컨텍스트에 전달할지 결정하고 감사를 위해 기록하며, 게임이 끝나면 격리가 올바르게 유지됐는지 자동으로 검증합니다. 음성 기능은 선택 사항입니다. |

## 프로젝트 유형

| 아이콘 | 유형 | 의미 |
| :--: | --- | --- |
| ✅ | **독립 실행** | 전체 코드가 이 저장소에 있으며, API 키를 설정하면 실행할 수 있습니다. |
| 📖 | **재현 가이드** | **외부 저장소**를 `git clone`해야 하는 상세 안내 문서입니다. |
| 🚧 | **설계 문서** | 아키텍처와 구현 계획만 있으며, 실행 가능한 코드는 아직 작성 중입니다. |
