模型 API 本身无状态。每次调用时，程序都要把规则、任务、模型决定和工具结果按顺序重新发送。

开发者规则

允许哪些行为，答案应满足什么标准

用户任务

查清问题，并提供可靠来源

模型请求调用工具

tool_calls: [{ id: "call_7", name: "search_web", ... }]

程序写回工具结果

tool_call_id: "call_7", content: "搜索结果..."

模型继续调用工具，或给出最终答案

谁负责什么

字段产生者作用
system开发者提供稳定规则
user用户描述本次任务
assistant.tool_calls模型请求工具名与参数
toolAgent 程序送回真实执行结果
配对规则：tool.tool_call_id 必须等于相应 assistant.tool_calls[].id。一次请求多个工具时，模型靠它判断每份结果属于哪个调用。
