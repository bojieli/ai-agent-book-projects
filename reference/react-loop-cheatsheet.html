一次循环，四个动作

模型只决定下一步；Harness 维护循环、执行工具、保存轨迹并强制停止。

  1. 读取上下文
  2. 决定下一步
  3. 执行工具
  4. 追加结果

最小骨架

messages = [规则, 用户任务]

for round in range(MAX_ROUNDS):
    decision = model(messages, tools)
    messages.append(decision)

    if decision requests tools:
        for call in decision.tool_calls:
            result = execute(validate(call))
            messages.append(result)
        continue

    if verify(decision.answer):
        return decision.answer

    messages.append("验证失败，请补充证据")

return "达到轮数上限，说明未完成原因"

三个退出口

成功答案通过明确验收标准
失败工具错误不可恢复
预算达到最大轮数或成本

调试时只检查四件事

  1. 模型是否收到正确的系统规则和工具定义？
  2. 模型请求的工具名与参数是否通过校验？
  3. 工具结果是否追加回同一个消息历史？
  4. 成功、失败和预算退出是否都能触发？
