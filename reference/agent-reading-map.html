用一个项目读懂全书

目标不是“读过十章”，而是每读一个机制，就让同一个 Agent 多一种可验证的能力。

第一轮：可用闭环

  1. 第 1 章 · 看懂循环

    产物：一个 LLM 能根据环境反馈反复选择工具，并在明确条件下停止。

  2. 第 2 章 · 管好上下文

    产物：稳定的系统指令、消息历史、状态与长度上限。

  3. 第 4 章 · 设计工具

    产物：两个窄权限工具，参数清楚、错误可观察、危险操作受约束。

  4. 第 7 章 · 证明可用

    产物：10 个真实任务、成功标准、运行轨迹和失败归因。

第二轮：按瓶颈选章

缺知识第 3 章：记忆与 RAG
缺行动第 5–6 章：代码与交互
缺协作第 10 章：多 Agent
缺模型能力第 8 章：后训练，最后考虑
缺持续改进第 9 章：从轨迹学习

读任何一节，只问四件事

  1. 环境：Agent 正在改变什么外部状态？
  2. 观察：做决定时，模型能看到哪些信息？
  3. 行动：模型可以调用哪些工具，权限边界在哪里？
  4. 验证：系统如何知道完成了、做对了，或应该停止？
通过标准：合上书后，能画出“观察 → 决策 → 行动 → 新观察”的循环，并能在自己的代码中指出每一部分。

依据：本书《导言》、第 1 章和《学习建议》。详细课程见 第 1 课。
