# آزمایش‌های فصل ۲: مهندسی کانتکست

پروژه‌های عملی مربوط به مدیریت پنجره کانتکست، خلاصه‌سازی و تزریق مهارت‌ها:
1. **کش کانتکست (KV Cache Reuse):** اندازه‌گیری تأخیر و هزینه.
2. **فشرده‌سازی کانتکست (Context Compression):** متدهای خلاصه عکس‌العملی.
3. **تزریق مهارت‌ها (Agent Skills):** بارگذاری پویای ماژول‌ها.
