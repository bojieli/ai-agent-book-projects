Lesson 0001 · 约 8 分钟

不要按章节读，要按闭环读

你真正要学会的不是复述十章目录，而是看见一个 Agent 如何观察世界、采取行动、验证结果，然后继续或停止。

  • 起点：三项入门认知
  • 终点：独立做出可用 Agent
  • 本课胜利：会安排第一轮阅读
本课唯一结论：始终用同一个小项目检验书中的机制。正文负责解释“为什么”，实验负责让你看到“改变哪里、结果怎样”。

先抓住一张图

第 1 章给出工程公式 Agent = LLM + 上下文 + 工具。把它放进环境后，真正运行的是一个循环：

观察 / 上下文模型此刻知道什么
决策 / LLM模型决定下一步做什么
行动 / 工具系统怎样读取或改变环境

工具执行后，环境产生新的观察，循环再次开始。可用系统还需要 Harness 提供约束、验证和纠正。因此，“模型回答得像不像”不是唯一标准；更重要的是系统能否做成、验真、停下。

第一轮只精读四章

  1. 第 1 章：建立最小循环

    精读 Agent/Environment、ReAct、Model–Harness 和停止条件。先读正文，再看 实验 1-1 的目标、入口和验收条件。

  2. 第 2 章：让循环不失忆、不失控

    精读 API 消息结构、工具调用循环、提示注入和上下文压缩。KV Cache 原理第一遍只记三条结论即可。

  3. 第 4 章：给 Agent 两只可靠的“手”

    选择两个真实工具，重点看工具描述、参数保真、权限和错误返回；MCP 是接入方式，不是学习终点。

  4. 第 7 章：证明它确实可用

    准备 10 个目标任务，写清成功标准，保存轨迹并找出第一个错误。没有评估的 Agent 只是 Demo。

第一轮完成后，再按瓶颈选章：需要记忆或知识库读第 3 章；需要文件与代码能力读第 5 章；需要语音、浏览器或异步事件读第 6 章；第 8–10 章留到你真的遇到模型能力、持续进化或协作瓶颈时。

每次阅读都留下一个改动

先用“资料研究 Agent”作为默认贯穿项目：输入问题，调用搜索与网页读取工具，输出带来源的答案，并检查引用是否真的支持结论。以后可以换项目，但不要频繁换主线。

  1. 读前：写下“这一节可能改变 Agent 的哪一部分”。
  2. 读中：只标出一个机制、一条边界和一个失败模式。
  3. 读后：在项目里做一个最小改动，运行同一组任务。
  4. 隔天：不看书画出循环，并解释改动为什么有效或无效。

哪种行为最可能让你真正读懂这本书？

现在只做一件事

阅读：第 1 章开头至“ReAct 循环”。

输出：不用查书，用四句话回答：环境是什么？Agent 看见什么？能做什么？怎样知道完成？

时间盒：20 分钟阅读，5 分钟回忆。遇到陌生细节先做问号标记，不展开搜索。
