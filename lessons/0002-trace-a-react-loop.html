亲手走一遍 ReAct 循环

用“查资料并给出可靠答案”这个任务，看清 Agent 为什么不是一次模型调用，而是一段由反馈推动的循环。

  • 已掌握：成功与失败退出
  • 本课只学：一轮怎样接下一轮
  • 本课胜利：能读懂最小循环
本课唯一结论：工具结果必须追加回上下文，模型才能根据真实反馈决定下一步。没有这一步，就没有闭环。

先看一次真实轨迹

用户说：“查清楚咖啡是否会影响睡眠，给出可靠来源。”Agent 预先拥有两个工具：search_web 搜索网页，read_url 读取正文。

轮次模型决定环境返回轨迹新增
1调用 search_web一组搜索结果工具调用 + 搜索结果
2读取两个可靠来源文章正文、作者、日期两次读取 + 两篇正文
3比较关键结论不再需要工具带引用的最终答案

第 2 轮之所以知道该读哪两篇，是因为第 1 轮的搜索结果已经进入轨迹；第 3 轮之所以能比较结论，是因为两篇正文也已经进入轨迹。

循环只有四个动作

  1. 读取上下文
  2. 决定下一步
  3. 执行工具
  4. 追加结果

然后回到第一个动作。模型在每一轮只决定“下一步”，不负责真的联网；Harness 负责校验工具调用、执行工具、保存结果并控制循环。

把你的停止规则放进代码

messages = [系统规则, 用户问题]

for round_no in range(MAX_ROUNDS):
    decision = model(messages, tools)
    messages.append(decision)          # 保存模型决定

    if decision.has_tool_calls:
        for call in decision.tool_calls:
            result = execute(call)
            messages.append(result)    # 保存真实观察
        continue                       # 带着新结果进入下一轮

    if has_two_reliable_sources(decision.answer):
        return decision.answer         # 成功退出

    messages.append("证据不足，请继续搜索")

return "达到搜索上限，说明无法确认的原因"  # 预算退出

书中的最小版本在“模型没有请求工具”时直接返回。这里多加了一次 has_two_reliable_sources 验证，因为你的目标是做出可用 Agent，而不是相信模型自己说“完成了”。
